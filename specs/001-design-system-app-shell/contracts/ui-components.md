# Component Library Contracts: `packages/ui`

**Feature**: Design System & App Shell (`specs/001-design-system-app-shell`)
**Date**: 2026-08-26

## Overview

All UI component primitives MUST reside in `packages/ui` and be exported through `packages/ui/src/index.ts`. Components are styled using Tailwind CSS classes that map directly to CSS Custom Properties generated by `packages/design-tokens`.

---

### Visual Specifications
- Minimum Height: 120px to maintain generous whitespace.
- Background: Consumes `var(--color-surface)` / `var(--color-surface-container)`.
- Elevation & Shadow: 1px border (`var(--color-outline-variant)`) with ambient shadow `0 4px 12px rgba(0,0,0,0.05)`.
- Interactive State: Hover elevates Y-offset by -2px; focus ring on keyboard tab.

### Visual Specifications
- Primary Button: 4px solid bottom border in darker tone (`border-b-4 border-primary-darker`).
